# ChikenRun

Otroška brskalniška igra v slogu klasičnega Moorhuhna — lovi lude kokoši!

## Igranje

1. Pritisni **Začni**.
2. Premikaj namerilnik z miško ali prstom.
3. Klikni / tapni, da ustreliš.
4. Ko zmanjka nabojev, pritisni **Naloži** (ali počakaj na samodejno nalaganje).
5. Krog traja **90 sekund**. Poskusi premagati svoj najboljši rezultat!

### Točke

- Daleč (majhne): 5
- Srednje: 10 / 25
- Blizu (velike): 50

Zadetki so prijazni: X-oči, padec, poof — brez nasilja.

## Tehnologija

- Vite + TypeScript + HTML Canvas
- Najboljši rezultat v localStorage
- Telefon celozaslonsko

## Razvoj

npm install
npm run dev
npm run build
